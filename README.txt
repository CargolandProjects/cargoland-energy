CARGOLAND ENERGY WEBSITE - cargolandenergy.com

HOW TO PUT IT LIVE
1. Unzip this file on a computer.
2. Upload EVERYTHING inside the "cargolandenergy.com" folder (index.html, the css, js and images folders, and all other .html pages) into your hosting's public folder (usually "public_html" in cPanel).
3. index.html must sit directly inside public_html, not inside a sub-folder.
4. Visit https://www.cargolandenergy.com to check.
